## Installing

Download the `.dmg` below, open it and drag **Safari Arcade** into **Applications**.

This build is not signed with an Apple Developer ID, so macOS and Safari each need one extra step. The [README](https://github.com/neilsethia2/arcade#installing) walks through them, and [docs/SIGNING.md](https://github.com/neilsethia2/arcade/blob/main/docs/SIGNING.md) explains why.
